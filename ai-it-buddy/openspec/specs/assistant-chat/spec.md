# assistant-chat Specification

## Purpose
Контракт чата между интерфейсом, ядром и агентом. Агент работает только через MCP-инструменты ядра и не видит данных вне прав пользователя.

## Requirements

### Requirement: Ход диалога через ядро
`POST /api/chat` SHALL передавать агенту сообщение, идентификатор треда и токен `mcp` пользователя и возвращать ответ и список вызванных инструментов. Если агент недоступен, ядро MUST вернуть 503 с понятным текстом, а не ошибку модели.

#### Scenario: LLM-провайдер исчерпал лимит
- **WHEN** шлюз моделей отвечает 429 на всех целевых моделях
- **THEN** пользователь получает сообщение, что помощник временно недоступен, ход отмечается в метрике ошибок чата

### Requirement: Действия только черновиками
Инструменты агента, меняющие состояние, SHALL создавать только черновики. Подтверждение, отмена, решения наставника и объявление инцидентов MUST быть доступны только через API интерфейса.

#### Scenario: Пользователь просит агента «сразу подтвердить»
- **WHEN** стажер пишет «оформи доступ и сразу подтверди»
- **THEN** агент создает черновик и просит нажать «Подтвердить» в интерфейсе
