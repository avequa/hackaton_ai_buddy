# mentor-digest Specification

## Purpose
Сводка наставнику перед встречей 1:1: прогресс, заявки, с какими темами стажер приходил, где база знаний не помогла, события безопасности. Текст переписки не хранится и не показывается.

## Requirements

### Requirement: Сводка по стажеру
`GET /api/mentees/{id}/digest` SHALL быть доступна только наставнику и руководителю стажера и MUST содержать готовые темы для разговора (talking points).

#### Scenario: Стажер застрял
- **WHEN** стажер трижды спрашивал про VPN и база знаний дважды не нашла ответ
- **THEN** в темах для разговора есть VPN и предложение дописать инструкцию

### Requirement: Еженедельная рассылка
Система SHALL раз в `DIGEST_INTERVAL` (по умолчанию неделя) присылать каждому наставнику уведомление со сводкой по каждому его стажеру.

#### Scenario: Наступила неделя
- **WHEN** прошел интервал рассылки
- **THEN** у каждого наставника в ленте уведомление `digest` по каждому стажеру со ссылкой на полную сводку
