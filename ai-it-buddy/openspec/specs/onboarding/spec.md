# onboarding Specification

## Purpose
Путь адаптации стажера: этапы, кто отмечает шаг, следующий шаг и прогресс для наставника.

## Requirements

### Requirement: Кто отмечает шаг
Шаг с исполнителем `self` SHALL отмечать стажер, шаг `mentor` - его наставник, шаг `lead` - его руководитель. Шаги, связанные с доступом, MUST отмечаться автоматически при выдаче доступа.

#### Scenario: Стажер отмечает шаг наставника
- **WHEN** стажер отмечает `setup-env`
- **THEN** ответ 403 и событие безопасности `forbidden`

#### Scenario: Чужой наставник
- **WHEN** наставник другого стажера отмечает шаг Анны
- **THEN** ответ 404, событие безопасности `foreign_object`

### Requirement: Прогресс для наставника
`GET /api/mentees` SHALL возвращать стажеров, у которых пользователь наставник или руководитель, с числом сделанных шагов и следующим шагом. Остальные стажеры MUST быть невидимы.

#### Scenario: Наставник открывает список
- **WHEN** Игорь (наставник Анны) запрашивает `GET /api/mentees`
- **THEN** в списке Анна с прогрессом, а стажера Марии в списке нет
