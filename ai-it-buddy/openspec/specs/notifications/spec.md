# notifications Specification

## Purpose
Лента уведомлений в окне чата: статусы заявок, решения для наставника, сбои, тревоги безопасности, сводки.

## Requirements

### Requirement: Лента с курсором
`GET /api/notifications?after={id}` SHALL возвращать уведомления пользователя с id больше `after`, старые сверху, не больше 100. `POST /api/notifications/read` MUST отмечать прочитанными уведомления до указанного id включительно.

#### Scenario: Интерфейс опрашивает ленту
- **WHEN** интерфейс раз в несколько секунд запрашивает ленту с последним известным id
- **THEN** приходят только новые уведомления

### Requirement: Только свои уведомления
Пользователь SHALL видеть только свою ленту.

#### Scenario: Наставник и стажер
- **WHEN** наставник открывает ленту
- **THEN** он видит запросы на решение и тревоги по своим стажерам, но не уведомления стажеров
