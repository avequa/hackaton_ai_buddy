# AI IT-Buddy — фронтенд

Подключён к API ядра (`src/api.ts` — Zod-схемы и клиент из контракта).

## Запуск
```bash
npm install        # поставит в том числе zod
npm run dev        # http://localhost:5173, /api проксируется на http://127.0.0.1:8080
```
Вместе с бэкендом в Docker: `cd ../ai-it-buddy && docker compose up -d --build`, интерфейс на http://127.0.0.1:3000
(сборка `node:22-alpine`, раздача и прокси `/api` - `nginx:alpine`, см. `Dockerfile` и `nginx.conf`).
Ядро должно работать на `127.0.0.1:8080`. Для другого адреса: `VITE_API_URL=http://host:port npm run dev`
(тогда нужен CORS на ядре).

## Структура
- `src/api.ts` — клиент и схемы (не править, источник правды — openapi.yaml)
- `src/lib.ts` — экземпляр `api`, подписи, статусы, форматирование дат
- `src/useChat.ts` — состояние чата (живёт при смене экранов, история в localStorage)
- `src/screens/*` — экраны: вход, модули, чат, заявки, путь адаптации, доступы, стажёры, согласования
- `src/App.tsx` — вход по токену, опрос заявок раз в 4 с, навигация по роли
- `src/router.tsx` — маленький роутер на History API (без зависимостей, учитывает `base` из Vite)
- `src/routes.ts` — все адреса страниц в одном месте (`paths`) и разбор URL (`matchRoute`)
- `src/theme.css` — все цвета приложения как CSS-переменные `--clr-*`
- `src/useFeed.ts` — опрос уведомлений, открытых сбоев и `/readyz`
- `src/feed.tsx` — колокольчик с лентой, баннер сбоя, окно стартового набора
- `src/Markdown.tsx` — ответы помощника в Markdown (без HTML, без зависимостей)
- `src/screens/Incidents.tsx` — сбои для SRE и руководителя

## Адреса страниц
| Путь | Страница | Роли |
|---|---|---|
| `/login` | Вход (`?next=` — куда вернуться после входа) | — |
| `/modules` (и `/`) | Модули | все |
| `/chat/access`, `/chat/support`, `/chat/equipment` | Чат с Buddy, выбранный модуль | все |
| `/requests`, `/requests/:id` | Мои заявки, открытая заявка | все |
| `/access` | Мои доступы | все |
| `/incidents` | Сбои: объявить и закрыть | sre, lead |
| `/onboarding` | Путь адаптации | стажёр |
| `/mentees`, `/mentees/:userId` | Стажёры, путь выбранного стажёра | наставник, руководитель |
| `/approvals` | Согласования | наставник, руководитель |

Неизвестный адрес показывает страницу 404; адрес, недоступный роли, ведёт на `/modules`.
При деплое нужен SPA-фолбэк (любой путь отдаёт `index.html`); Vite dev/preview делают это сами.

## Цвета
Менять цвета нужно только в `src/theme.css`. В `index.css` цвета подключены как `var(--clr-…)`,
основные имеют смысловые названия (`--clr-accent`, `--clr-text`, `--clr-bg`, `--clr-border`, `--clr-danger`…).
