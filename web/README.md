# web

Интерфейс AvitoBuddy: React 19, Vite 8, TypeScript. Работает с API ядра (`../ai-it-buddy`), ответы проверяются схемами Zod из `src/api.ts`.

## Запуск

Вместе со всем проектом в Docker (из `../ai-it-buddy`):

```bash
docker compose up -d --build      # интерфейс: http://127.0.0.1:3000
```

Образ собирается на `node:22-alpine`. Статику раздаёт `nginx:1.29-alpine`, он же проксирует `/api` на ядро, поэтому CORS не нужен (`Dockerfile`, `nginx.conf`).

Для разработки, когда бэкенд запущен в Docker:

```bash
npm install
npm run dev                       # http://localhost:5173, /api проксируется на 127.0.0.1:8080
```

Другой адрес ядра: `CORE_URL=http://host:port npm run dev`.

## Тесты

Без локального Node — в Docker вместе с остальными модулями: `bash ../ai-it-buddy/scripts/test-docker.sh`.

С Node.js 22, установленным внутри WSL или Linux (npm из Windows не подойдёт: он не работает с путями WSL):

```bash
npm test                          # 28 тестов, около 8 секунд
npm run coverage                  # покрытие строк ~95%, отчёт в coverage/index.html
npm run typecheck
```

Тесты рендерят приложение целиком. Вместо ядра отвечает поддельный бэкенд (`tests/fakeBackend.ts`) с теми же адресами и форматами. Сеть и модель не нужны.

Что проверяется:
- вход и выход;
- чат: черновик, подтверждение, отмена, ошибка помощника, Markdown;
- заявки, план адаптации, доступы, стартовый набор;
- уведомления, баннер сбоя;
- экраны наставника, SRE и руководителя;
- доступ к экранам по роли.

## Экраны

| Путь | Экран | Роли |
|---|---|---|
| `/login` | вход, выбор сотрудника | — |
| `/modules` | главная: модули, стартовый набор | все |
| `/chat/access`, `/chat/support`, `/chat/equipment` | чат с помощником | все |
| `/requests`, `/requests/:id` | заявки и карточка заявки | все |
| `/access` | выданные доступы | все |
| `/onboarding` | план адаптации | стажёр |
| `/mentees`, `/mentees/:id` | стажёры, сводка к встрече 1:1, тревоги | наставник, руководитель |
| `/approvals` | заявки не по роли | наставник, руководитель |
| `/incidents` | объявить и закрыть сбой | SRE, руководитель |

Во всех экранах есть колокольчик с уведомлениями, баннер открытого сбоя и плашка, если база временно недоступна. Обновления приходят опросом: уведомления — раз в 4 секунды, заявки — пока есть незавершённые.

| `src/App.tsx` | вход по токену, загрузка данных, навигация по роли |
| `src/useChat.ts`, `src/useFeed.ts` | состояние чата; опрос уведомлений, сбоев и `/readyz` |
| `src/feed.tsx` | колокольчик, баннер сбоя, окно стартового набора |
| `src/Markdown.tsx` | ответы помощника: абзацы, списки, жирный, код, без HTML |
| `src/router.tsx`, `src/routes.ts` | роутер на History API и все адреса страниц |
| `src/screens/` | экраны |
| `src/theme.css` | цвета (CSS-переменные `--clr-*`) |
| `public/brand-logo.png` | значок в шапке; без файла показывается значок-искра |
